# Ziki Preview Test Frontend

A minimal mock React demo built with Vite. It has no backend: the sample tasks are hardcoded, and your changes are saved in the browser's `localStorage`.

The task board lets you tick tasks off, rename them (double-click or the pencil button; Enter saves, Escape cancels) and reorder them (drag on desktop, or the arrow buttons). **Reset sample tasks** restores the original list.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

The output goes to `dist/`.
